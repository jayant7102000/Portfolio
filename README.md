---

## Why this portfolio
This portfolio is designed for **recruiters and hiring managers** to quickly understand:
- What I work on
- The technologies I use
- The kind of problems I enjoy solving
- How I present and communicate my work

It focuses on clarity, performance, and real-world relevance rather than visual clutter.

---

## Key Features
- Clear professional introduction
- Projects section with descriptions and links
- Skills and technology overview
- Resume access (if enabled)
- Contact section
- Responsive design for desktop and mobile

---

## Tech Stack
- **Frontend:** React.js, JavaScript (ES6+)
- **Styling:** HTML5, CSS3, Styled Components
- **Version Control:** Git, GitHub
