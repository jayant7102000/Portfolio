# Portfolio

A personal portfolio website built with React to showcase my projects, skills, and experience.

Live site: https://jayant-jathar-portfolio.netlify.app/

## Overview
This portfolio is a React application that highlights my background, featured projects, and ways to connect with me. It is designed to be simple, fast, and easy to update by editing the data/config files.

## Features
- About section with a brief introduction
- Projects section with links and descriptions
- Skills/tech stack section
- Resume download/link (if enabled in the site)
- Contact section

## Tech Stack
- React.js
- JavaScript (ES6+)
- HTML5 / CSS3
- Styled Components (if used in the project)
- Git & GitHub
